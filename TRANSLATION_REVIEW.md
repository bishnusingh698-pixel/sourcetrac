# Translation review — Templates, Insight Library and Survey Studio

Every string this build adds, grouped by language, so a native speaker can
review it. **English (`en`) is the source** and is shown first; each other
column is that language's translation of the same key.

Two string sets:

- **Template content** — `shared/templates/locales/<code>.json` (405 keys).
  Template names, one-liners, learn bullets, question text, answer options,
  ideas, tag text and tooltips, packs and season banners. Highest review value.
- **Admin UI** — `app/lib/i18n/locales/<code>.json`, the plan's namespaces
  (`library.*`, `templates.*`, `results.*`, `studio.*`, `confidence.*`,
  `ideas.*`, `home.*`, `setup.*`, `ready.*`, `smart_actions.*`) (279 keys).

How to use this file: send the section for one language to a native speaker and
ask them to flag anything that reads unnaturally, is too long for its button, or
uses a wrong register. Brand names (Instagram, TikTok, …) are intentionally
untranslated. German uses the formal *Sie*; the other languages use the informal form.

A key-parity test (`tests/unit/template-locales.test.ts` and `tests/i18n.test.ts`)
fails if any key in `en` is missing from another language, so coverage is enforced;
this file is for *quality*, not coverage.
